# VS Code Setup for LEGO EV3

## Development Environment

The robot was programmed using Python with Visual Studio Code as the code editor.

## Hardware Setup

- LEGO MINDSTORMS EV3 Brick
- MicroSD card
- USB cable
- Laptop running Visual Studio Code

## Software Used

- Python
- Visual Studio Code
- EV3Dev2 Python library

## Setup Process

1. Prepare the microSD card with the EV3 operating system.
2. Insert the microSD card into the EV3 Brick.
3. Connect the EV3 Brick to the laptop using a USB cable.
4. Open the Python project in Visual Studio Code.
5. Write and edit the robot's Python program.
6. Transfer the program to the EV3 Brick.
7. Run and test the program on the robot.

## Main Program

The main program is stored in:

`src/sorter.py`

It controls colour detection, robot movement, and the block-sorting mechanism.
