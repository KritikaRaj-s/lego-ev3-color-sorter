# LEGO EV3 Color Sorter Bot

A LEGO EV3 robot that detects and sorts red, yellow, and green blocks using Python.

## About the Project

This project is a color-sorting robot built using LEGO MINDSTORMS EV3. It uses a color sensor to identify the color of a block and a motorized mechanism to sort it into the appropriate location.

## How It Works

1. The robot starts from its home position.
2. The color sensor detects the block's color.
3. The robot moves to the corresponding drop location.
4. A motorized mechanism pushes the block into the correct section.
5. The robot returns to its home position.
6. It is ready to sort the next block.

- Green
